# Changelog

## 2.0.4 — First public release

- Ship the online installer with real download progress, cancellation, hash verification and safe retry.
- Pin authenticated LibreOffice 26.2.6 and verify the complete engine file inventory.
- Keep processing local, with conversion, compression presets, advanced controls, queues and comparison.
- Include English and Portuguese, the OLED interface and current Windows icon.
- Add public build instructions, security policy and third-party notices.
