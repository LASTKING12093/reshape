# Security policy

Security fixes target the latest Reshape release. Older releases are not maintained separately.

Please do not post vulnerabilities, sensitive logs, or private files in public issues. Use **Security → Report a vulnerability** on the GitHub repository when private reporting is available. If that option is unavailable, open an issue asking for a private contact method without including vulnerability details.

Include the affected version, a description of the impact, and minimal steps using synthetic files. Please give maintainers time to investigate before publishing details.

Reshape processes files locally using managed third-party tools downloaded by setup. These tools have their own security advisories and licenses. A local application still needs updates and care when opening untrusted files.
